# HelixZone Quick Start Guide

This quick start guide will help you get up and running with HelixZone in minutes. Follow these tutorials to learn the basics of image editing with HelixZone.

## Tutorial 1: Basic Image Editing

### Opening and Setting Up
1. Launch HelixZone
2. Click `File > Open` or press `Ctrl+O`
3. Select an image to edit

### Basic Adjustments
1. **Brightness/Contrast**
   - Go to `Image > Adjustments > Brightness/Contrast`
   - Adjust sliders to enhance image
   - Click "Apply"

2. **Crop Image**
   - Select Crop tool (C)
   - Drag to create crop area
   - Press Enter to apply

### Saving Your Work
1. Click `File > Save As` (`Ctrl+Shift+S`)
2. Choose format (PNG recommended)
3. Select location and click Save

## Tutorial 2: Working with Selections

### Basic Selection
1. Choose Rectangle Selection tool (M)
2. Click and drag to select area
3. Try holding Shift for perfect square
4. Practice adding (Shift) and subtracting (Alt)

### Using Lasso Tool
1. Select Lasso tool (L)
2. Draw around object
3. Release to complete selection
4. Try Magnetic Lasso for edge detection

### Modifying Selection
1. Right-click selection
2. Choose "Feather"
3. Enter radius (e.g., 5px)
4. Apply changes

## Tutorial 3: Layer Basics

### Creating Layers
1. Click "+" in Layers panel
2. Try different blend modes
3. Adjust opacity

### Layer Masks
1. Select layer
2. Click "Add Layer Mask"
3. Paint black to hide
4. Paint white to reveal

## Tutorial 4: Using Tools

### Brush Tool
1. Select Brush (B)
2. Adjust size with [ ]
3. Change opacity (number keys)
4. Paint on canvas

### Eraser Tool
1. Select Eraser (E)
2. Adjust size and hardness
3. Erase unwanted parts

## Practice Project: Photo Enhancement

Follow this mini-project to practice what you've learned:

1. **Open Image**
   - Open a portrait photo
   - Create duplicate layer

2. **Enhance**
   - Adjust brightness/contrast
   - Apply subtle sharpening
   - Remove blemishes

3. **Selective Editing**
   - Use Lasso to select face
   - Apply skin smoothing
   - Adjust eye brightness

4. **Finishing**
   - Add final adjustments
   - Save in high quality
